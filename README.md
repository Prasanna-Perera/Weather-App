# 🌦️ Weather App

A clean, responsive web application that provides real-time weather updates for cities around the world. Built using vanilla web technologies.

## 🔗 Live Demo
You can view the live deployed version of this app via [GitHub Pages](https://prasanna-perera.github.io/Weather-App/).

## ✨ Features
- **Real-Time Weather Data:** Search for any city to view current temperature, humidity, wind speed, and weather conditions.
- **Responsive Design:** Works seamlessly across desktop and mobile devices.
- **Dynamic UI:** Updates weather icons and visuals based on current atmospheric conditions.

## 🛠️ Built With
- **HTML5** – Structure and layout
- **CSS3** – Styling and responsive design
- **JavaScript (ES6+)** – API integration and DOM manipulation
